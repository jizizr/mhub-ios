# 两端交互与界面规范

目标：保留网页版的操作逻辑，界面换成各平台原生控件，并参照 Apple Music 的设计语言。两端的页面结构、按钮位置、手势和文案保持一致；只有「控件由谁画」不同。

改动交互时先改这份文档，再同时改两端。

## 页面结构

```text
根导航（三个标签，与网页手机端一致）
├─ 主页      推荐：心情标签 → 推荐歌单（横向卡片）→ 推荐歌曲（网格）→ 最近播放
├─ 资料库    歌单（本地）、本地缓存、导入歌单；歌单详情
└─ 搜索      平台选择 + 搜索框 + 结果列表
迷你播放器  贴在标签栏上方，所有根页面可见
全屏播放器  从迷你播放器展开：封面／歌词／待播清单三种视图
设置        主页右上角头像按钮进入：服务器、音质、平台、歌词、缓存、关于
```

| 元素 | iOS（SwiftUI，iOS 26+） | Android（Glasmio，API 33+） |
| --- | --- | --- |
| 标签栏 | `TabView` + `Tab`，搜索用 `Tab(role: .search)`；`.tabBarMinimizeBehavior(.onScrollDown)` | `GlasmioNavigationBarWithTrailingItem`，搜索是独立的尾部胶囊；滚动收缩由 `rememberGlasmioNavigationScrollState` 驱动 |
| 迷你播放器 | `.tabViewBottomAccessory`（系统液态玻璃附件，随标签栏收缩切换 inline） | `GlassSurface` 胶囊，贴在导航栏上方 8 dp，随导航栏收缩 |
| 大标题页 | `NavigationStack` + `.navigationTitle` + 大标题 | `GlasmioPinnedListPage`（断点收缩的大标题） |
| 全屏播放器 | `.fullScreenCover` + 缩放转场（系统下滑关闭）；液态玻璃控件 `glassEffect` | 全屏覆盖层 + 下滑关闭；`GlassSurface` 控件、`GlasmioVolumeSlider` |
| 歌曲菜单 | 行尾「…」`Menu` + 长按 `.contextMenu` | 行尾「…」`GlasmioMenu`（iOS 风格下拉） |
| 列表 | `List` inset grouped | `GlasmioGroupedList` + `GlasmioListRow` |
| 设置 | `Form` | `glasmio-preference` 行 |
| 搜索 | 页内常驻 `.searchable`（标签栏带附件时 iOS 不会把搜索框并入底栏）+ 平台胶囊 | `GlasmioSearchBar` + `GlasmioScrollableTabRow` 平台胶囊 |
| 图标 | SF Symbols | `SfIcon` 语义名 → `MHubIcons` 自绘的 iOS 风格矢量（播放、跳转、歌词、输出、列表、资料库等），其余退回 Material |
| 强调色 | 资源目录 `AccentColor`（#FA2D55） | `MHubAccent`（同色） |
| 页面背景 | 歌曲列表类页面（主页、搜索、歌单／专辑详情）白／黑；资料库、设置、缓存为分组灰 | 同左（`plainBackground()` 与 `groupedBackground`） |

## 歌曲操作（两端相同的菜单顺序）

- 点歌曲行：**立即播放**——插到当前曲之后并开始播放；已在队列中则移过去，不重复（网页 `playNow`）。
- 列表头的「播放」「随机播放」：用整个列表**替换**队列（网页 `playFrom`）；随机开启时随机选第一首。

长按（iOS 也可点行尾「…」）弹出：

1. 播放下一首（插到当前曲之后；已在队列中则移动过去，不重复）
2. 添加到播放队列（追加到末尾，排在自动续播推荐之前）
3. 添加到歌单…
4. 分享（网页链接 `?song=<platform>:<id>`）
5. 从歌单删除（仅歌单详情页）

「立即播放」「替换」「追加」「下一首播放」是四个独立操作，与网页一致。

## 播放器

- 音质以**开始播放时**的设置为准；切换音质不打断当前曲，从下一首生效（全屏播放器音质标记可立即用新音质重播当前曲）。
- 上一首：已播放超过 3 秒时回到开头，否则切到上一首。
- 重复：全部 → 单曲 → 关闭循环；开启重复会关闭自动续播。开启自动续播会关闭重复。
- 随机：当前曲移到第一位，其余打乱；自动续播的推荐始终排在最后。关闭随机恢复原顺序（随机期间新增的歌也保留）。
- 自动续播（∞）：只对 Apple Music 曲目；队列剩余不超过 2 首时，用最近 10 首作种子请求电台，之后复用同一电台。关闭时删掉尚未播放的推荐。
- 下一首预取：当前曲**完整缓存后**才解析下一首并交给系统播放器排队，保证无缝衔接且不和当前曲抢带宽。
- 后台：系统媒体会话由系统播放器持有（iOS `AVQueuePlayer` + Now Playing；Android Media3 `MediaSessionService`）。下一首在当前曲结束前已排进系统播放器，锁屏不会掉通知。
- 队列逻辑由 `contract/queue-cases.json` 约束，两端单测执行同一组用例。

### 全屏播放器布局（自上而下，参照 Apple Music）

1. 下拉把手
2. 封面（暂停时缩小，播放时放大，弹簧动画）／或歌词／或待播清单
3. 标题、艺人（过长滚动），右侧「…」菜单（加入歌单、分享、查看歌单）
4. 进度条（拖动时放大）+ 已播／剩余时间，中间显示音质标记（无损／Hi-Res／高品质），点按在标记正上方居中弹出音质菜单（高到低，当前项打勾，深色材质）
5. 上一首 · 播放／暂停 · 下一首（大号，按下回弹）
6. 音量：细胶囊滑块（拖动时变粗），两端扬声器图标。iOS 经隐藏的 `MPVolumeView` 调系统音量，取不到系统滑块（模拟器）时改播放器音量；Android 调 `STREAM_MUSIC`
7. 底部三按钮：歌词 · 输出设备（iOS AirPlay；Android 14+ 系统输出切换面板）· 待播清单

背景：封面放大模糊铺满，叠一层随封面取色的渐变，缓慢流动。

### 歌词（参照 Apple Music）

- 逐字模式与网页相同：仅原生逐字 / 估算逐字 / 整行。原生端默认「估算逐字」（网页默认「仅原生」）：没有逐字时间的行按音节拆分，CJK 一字一单位、拉丁词按元音组加权，每单位 120–600 ms，只占到下一行前 90% 的时间。算法与网页 `word-timing.js` 一致，用 `contract/lyrics-estimate-cases.json`（由网页实现生成）约束两端。
- 当前行固定在面板约 30% 高度；换行时每一行用弹簧移到新位置，下方的行依次多延迟 45 ms，形成级联。只有当前行变化才做动画，行高变化等布局修正直接跳位。
- 打开歌词时直接显示当前行：歌词在封面移走期间隐藏排版，等行高稳定（打开 0.6 s 后且 0.25 s 内无行高变化）后在目标位置淡入，不出现滚到目标行的过程。
- 字内扫光：每个字是暗色底层加亮色上层，上层用 30% 宽的柔边渐变从左向右显露；唱到的字上浮约 2.5pt；持续 1 秒以上的长音发光并轻微放大。
- 非当前行变暗并缩小到 97%（以左侧为锚），距当前行两行以外再暗一档；不做距离模糊。唱完的行淡出回暗色，不突变。
- 背景人声小一号，随主行一起点亮。
- 前奏、或两行间隔超过 4 秒的间奏：在下一行上方显示三个依次填满、轻微呼吸的圆点。
- 手动拖动歌词时暂停跟随，松手 3 秒后弹回当前行；点任意一行跳到该行时间。
- 翻译、音译挂在最近的主行（1 秒以内）下方。
- 简繁转换：原文 / 简体 / 繁體，用系统 ICU 转写（iOS `StringTransform`，Android `android.icu.text.Transliterator`），不打包词典。

### 过渡动画

| 场景 | iOS | Android |
| --- | --- | --- |
| 页面推入／返回 | `NavigationStack` 系统转场，左缘滑动返回 | 临界阻尼弹簧（约 0.5 s）：新页从右滑入，下层页左移三分之一并变暗；`SeekableTransitionState` + 预测性返回，手势拖动时页面跟手 |
| 打开全屏播放器 | 从底栏附件缩放展开（`.zoom`） | 迷你播放器与全屏播放器共享边界，从胶囊长成全屏；下拉跟手缩小，松手缩回胶囊 |
| 封面 ↔ 歌词／待播清单 | `matchedGeometryEffect` | 共享元素，封面在大图与左上角小图之间移动 |
| 按压 | 系统按钮与列表高亮 | 全局 iOS 式按压：按钮大小的目标整体变淡（无方形阴影），列表行灰色高亮（替代 Material 水波纹）；卡片按下缩小 4% 并回弹 |
| 迷你播放器收起 | `tabBarMinimizeBehavior(.onScrollDown)`，附件并入底栏 | 按 MeiloX 测得的几何：滚动收起时胶囊缩到主页与搜索按钮之间、只留标题，横竖两路弹簧错开 |

## 设置项（两端同名同序）

| 分组 | 项 | 默认 |
| --- | --- | --- |
| 服务器 | 服务器地址（保存前请求 `/health` 校验） | 空，首次启动引导填写 |
| 播放 | 音质：标准／高品质／无损／Hi-Res | 高品质 |
| 播放 | 自动续播 | 关 |
| 搜索 | 默认平台 | Apple Music |
| 歌词 | 文字：原文／简体／繁體；显示翻译；显示音译 | 原文；开；关 |
| 外观 | 跟随系统／浅色／深色 | 跟随系统 |
| 存储 | 音频缓存占用、上限、清除（不影响歌单） | 上限 2 GB |
| 关于 | 版本、开源许可、源代码链接 | — |
